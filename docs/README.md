# JoyRide documentation

JoyRide is an open-source, hobby electric go-kart project. The journey is the goal. Documentation rules are in [CLAUDE.md](../CLAUDE.md).

## Core documents

Read in this order:

1. [PROJECT.md](project/PROJECT.md): charter, constraints, process, safety, budget, and rhythm.
2. [GOALS.md](project/GOALS.md): needs, system requirements, and learning goals.
3. [SUBSYSTEMS.md](architecture/SUBSYSTEMS.md): architecture, interfaces, and what each subsystem owns.
4. [RISKS.md](project/RISKS.md): the risk register.
5. [STG-1](stages/STG-1-ARCHITECTURE.md): what to do first.
