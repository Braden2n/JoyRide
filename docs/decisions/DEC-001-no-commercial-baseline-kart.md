# DEC-001: No commercial baseline kart

## Context

The project could start by buying a complete commercial kart and replacing parts, or start with subsystem work and integrate later.

## Options

| Option | Pros | Cons |
| --- | --- | --- |
| Buy a commercial kart first | Drivable early | Spends money before learning; anchors the design to someone else's choices |
| Start with subsystem work | Learning first; nothing bought before a spend checkpoint | No drivable kart until integration |

## Decision

Start with subsystem work. Commercial parts appear later only as placeholders for subsystems that have not had their turn.

## Consequences

The kart MVP is a result of integration ([STG-3](../stages/STG-3-INTEGRATION.md)), not a starting point.
