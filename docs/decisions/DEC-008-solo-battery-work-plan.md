# DEC-008: Solo battery work under a written safety plan

## Context

PROJECT.md Safety says never work alone on the battery. The builder always works alone, so the rule cannot be met. The question was raised in #8 and is open item 1 of [STG-2-PACK](../stages/STG-2-PACK.md). The answer is recorded here, and the plan is in [SOLO-SAFETY](../procedures/SOLO-SAFETY.md).

## Options

| Option | Pros | Cons |
| --- | --- | --- |
| Keep the rule and skip battery work | Matches the rule as written | Blocks PACK, the cycle that depends on the battery |
| Find a second person for battery work | Meets the rule as written | The builder always works alone, so this cannot be met |
| Allow solo battery work under a written safety plan | Lets PACK proceed and keeps the risk controls | The rule now has an exception the builder must follow |

## Decision

Allow solo battery work under [SOLO-SAFETY](../procedures/SOLO-SAFETY.md). The PROJECT.md Safety rule now applies only when that plan does not.

## Consequences

- [PROJECT.md](../project/PROJECT.md#safety) Safety now names the solo plan as the exception.
- [STG-2-PACK](../stages/STG-2-PACK.md) open item 1 is resolved in #8.
- [SOLO-SAFETY](../procedures/SOLO-SAFETY.md) is the controlling procedure for solo battery work, and it stays in draft until the builder reviews it.
